# エアロバブル 仕様書

## 1. 概要と今回の範囲

同じ色の泡を指でなぞってつなぎ、はじけさせる60秒のパズル。フルティガーエアロ（晴れた空・つややかな海・ガラスの泡）の世界で、遊ぶほどアクアリウムの仲間が増える。企画は [PLAN.md](PLAN.md)。

今回の試作：1回のあそび（つなぐ・特別な泡・エアロタイム・コンボ・時間切れの締め）、6つの画面、記録と再開、音、書き出しと読み込み。

## 3. ルール

### 盤面

- 7列×8行の六角形の並び。列は縦にまっすぐ、奇数の列は半マス下にずれる。隣は最大6つ
- 泡は5色。色ごとに印がある（しずく・はっぱ・たいよう・はな・ほし）
- 泡は水に浮かぶ：消えたぶん残りは上へ詰まり、新しい泡は下から湧く（色は種つきの乱数）
- 消せる手（同じ色が3つ以上つながったかたまり、または特別な泡）がなくなったら並べ直す

### 命令（ルール本体への入力）

| 命令 | はたらき |
|---|---|
| press(マス) | ふつうの泡ならつなぎ始め。特別な泡なら、離したときにはじける |
| enter(マス) | 最後の泡の隣の同じ色ならつなぐ。1つ前の泡に戻ったら最後の1つを外す |
| release() | 3つ以上つないでいれば消す。足りなければ取り消し。特別な泡を押していたらはじける |
| cancelTouch() | つないだ泡を外す（ほかの指・一時停止） |
| step() | 1刻み（0.05秒）進める |

### 消す・特別な泡

- n つなぎの点 = 100×n ＋ 100×k(k+1)/2（k = n−3）。例：3で300、5で800、7で1,700、11で4,700
- 7以上つなぐと、最後の泡の場所にアクアボム、11以上ならプリズムが生まれる
- アクアボム：タップで距離2までの泡（最大19個）を消す
- プリズム：タップで、つないだ色の泡をすべて消す
- 範囲に入ったほかの特別な泡も続けてはじける（連鎖）。1個につき120点＋ボム500点・プリズム1,000点

### コンボとエアロタイム

- 前に消してから2.5秒以内に消すとコンボが続く。倍率は 1 ＋ 0.04×(コンボ−1)（最大25コンボぶん、2倍まで）
- 消した泡の数でエアロゲージがたまる（最初50個、1回ごとに＋10、最大90）
- いっぱいになるとエアロタイム：6秒間、残り時間が減らず、点が2倍。この間はゲージがたまらない

### 時間

- 数え始め3秒 → 60秒 → 時間切れ
- 時間切れのとき3つ以上つないでいれば、そのまま消える（すべりこみ）
- 残った特別な泡は0.4秒ごとに自動ではじけ（コンボとエアロタイムの倍率なし）、1.2秒おいて結果
- 残り5秒から1秒ごとに知らせる

### 乱数

- 泡の色と並べ直しは、種つきの疑似乱数（mulberry32）だけで決める。状態は RoundState.rng に持つ
- 同じ種・同じ命令の並びなら同じ結果（tests/determinism.test.ts）

## 6. セーブ

- 保存の窓口は SaveStore（localStorage、鍵 `aero-bubble/save`）。版番号 SAVE_VERSION = 1、古い版の変換は src/save/migrations.ts
- 保存するもの：設定（効果音・音楽・振動・動き）、記録（ベスト・回数・合計の泡・合計のエアロタイム・最長つなぎ・1回のエアロタイムの最多・仲間・あそびかたを見たか・最近の点数10回）、あそびの途中の盤面、最後の結果
- あそびの途中は5秒ごと・画面が隠れたとき・一時停止で保存。再読み込みすると一時停止のまま「つづきから」
- 閉じていた間は進めない（パズルなので、隠れたら止める）
- 書き出しは `AERO1.` ＋ base64。途中の盤面は入れない。読み込むときは長さ・数の上限と形を Zod で確かめ、知らない鍵は落とす
- 保存できない環境（プライベートブラウズなど）は知らせる

## 7. 操作

- なぞる：泡に指を置き、同じ色の隣へ動かす。速く動かしても、通った道を泡の半径の0.3倍ごとに調べて飛ばさない
- 当たり：触れ始めは泡の半径の1.05倍、なぞる途中は0.8倍（斜めに通るとき隣を拾いすぎない）
- 戻る：1つ前の泡に指を戻すと最後の1つが外れる
- タップ：特別な泡を押して、そのまま離す
- 指の操作は画面全体を包む要素で受け取る（canvas には取らせない）。ほかの指は無視する
- Esc キー：一時停止

## 8. 見た目の決まり

- 書体は M PLUS Rounded 1c（1つ）
- 文字は濃い紺（--ink #0b2b4c）をガラスの上に置く。明るさの比 4.5:1 以上
- つやボタン：緑＝すすむ（あそぶ・つづける・もういちど）、青＝ほか、赤＝消す
- 泡の色は5色＋印。つないでいる間、つなげない泡は暗く沈める
- 画面の文字は HTML に置き、PixiJS には描かせない
- 動きを減らす設定：景色の動き・ばね・しぶきを止め、知らせは動かさずに出す
- 押せる物は44px以上。泡の直径は、どの画面でも44px以上（e2e で確かめる）
