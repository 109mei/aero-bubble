# エアロバブル 企画書

## ひとことで

晴れた空とつややかな海の「フルティガーエアロ」の世界で、同じ色の泡を指でなぞってつなぎ、はじけさせる60秒のパズル。遊ぶほど海の仲間（魚・クジラ・虹・風車・地球）が増えていく。

## テーマ：フルティガーエアロ

2000年代後半のデジタルの景色（Windows Vista／7 の Aero、つやのあるボタン、水と空と緑、泡、レンズの光）がもつ「明るい未来と自然が仲よく並ぶ」気分を、遊びの手ざわりにする。

| 要素 | ゲームでの形 |
|---|---|
| 泡・水滴・ガラス | 盤面の泡はつやのあるガラス玉。消えると水しぶきときらめき |
| 青い空と緑の丘（Bliss） | 画面の上は空と丘、下は光の差しこむ海（上下に分けた眺め） |
| レンズの光・太陽 | 空の太陽と、画面にかかるレンズの光の輪 |
| オーロラ | ゲージがたまった「エアロタイム」で、空と海にオーロラがかかる |
| 自然とテクノロジー | 風車・地球・海の生き物がアクアリウムの仲間として増える |
| つやのボタン・ガラスの窓 | 画面の部品は、上半分が光る「つやボタン」と、すりガラスの板 |

## なぜスマホで遊びたくなるか

- 片手の親指1本。なぞって離すだけで、説明なしでも遊べる
- 1回60秒（エアロタイムで少し延びる）。すき間の時間に何度でも
- つなぐたびに音が1段ずつ上がり、離すと泡が次々にはじける気持ちよさ
- 長くつなぐと特別な泡（アクアボム・プリズム）が生まれ、まとめて消せる逆転の手がある
- 遊ぶたびに海がにぎやかになり、最後は空に地球が浮かぶ（集める楽しみ）

## 遊びの流れ（1回）

1. 3・2・1 で始まる
2. 同じ色の泡をなぞって3つ以上つなぎ、離して消す。泡は水に浮かぶので、残りは上へ詰まり、下から新しい泡が湧く
3. 7つ以上でアクアボム、11以上でプリズムが生まれる。タップでまとめて消す
4. 消した泡でエアロゲージがたまると「エアロタイム」：6秒間、時間が止まって点が2倍
5. 続けて消すとコンボで点が上がる（2.5秒あくと切れる）
6. 時間切れ。なぞっている途中のつなぎは「すべりこみ」で消え、残った特別な泡は自動ではじける
7. 結果：点数・記録・新しい仲間

## 長く遊ぶ理由

- 最高点を更新する（上手になるほど点が大きく伸びる。慣れた人は初めての人の約4倍）
- アクアリウムの仲間11種を集める（1回目で2種、約24回でぜんぶ）
- 仲間は景色として海を泳ぎ、空に並ぶ

## 今回の試作で作る範囲

- 1回60秒のあそび（つなぐ・アクアボム・プリズム・エアロタイム・コンボ・すべりこみ・自動ではじける締め）
- タイトル・結果・一時停止・あそびかた・アクアリウム・設定
- 記録（最高点・回数・合計・仲間）と、あそびの途中からの再開
- 効果音と音楽（その場で合成）、振動（対応端末）
- 記録の書き出し・読み込み
- スマホ縦画面（390×844 を基準に、幅いっぱい・高さは伸び縮み）

作らないもの（あとで考える）：夜の海（暗い画面）、毎日同じ海で競う「きょうの海」、ランキング、PWA（ホーム画面から電波なしで遊ぶ）
